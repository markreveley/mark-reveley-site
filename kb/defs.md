  A network is a collection of devices that exchange data. A router forwards data between networks. Each participating router is a node in the mesh. Mesh means nodes can cooperate through multiple connections; every node
  does not need a direct connection to every other node.

     An operating system manages hardware and provides the environment in which programs run.

     Linux kernel: the central software that manages memory, hardware, and networking. The kernel does much of the actual work of forwarding traffic.

     a daemon, meaning a background program that keeps working without an open application window. A process is a running instance of a program.
