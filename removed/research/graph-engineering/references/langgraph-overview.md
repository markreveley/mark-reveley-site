# About

The reference documentation for the dominant graph-orchestration framework (per [Data Science Dojo](dsdojo-frameworks-before-name.md) and [LangChain's own numbers](langchain-3-years-langgraph.md)). Two load-bearing facts for this bundle: the design goal of mixing deterministic hand-coded steps with LLM-driven steps in one graph, and the acknowledgements line tracing the runtime to Google's Pregel (2010) — a direct wire from classical large-scale graph processing to 2026 agent orchestration.
