# Views

Non-narrative compositions over the quote DAG. A view arranges excerpts (by
time, by tag, by dependency) without adding conclusions; per the house rule
([README](../README.md)), any position a view takes is implicit in what it
selects and how it connects it. Synthesis documents live in `ob6to8/direction`:
[`mark_reveley/2026-08-25-graph-engineering-synthesis/`](https://github.com/ob6to8/direction/blob/main/mark_reveley/2026-08-25-graph-engineering-synthesis/README.md).
