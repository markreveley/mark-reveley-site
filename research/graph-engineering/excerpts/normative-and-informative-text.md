# Quotes

> "normative: Text in a specification which is prescriptive or contains conformance requirements." [^w3c]

> "informative: Text in a specification whose purpose is informational or assistive in the understanding or use of the specification, and which contains no conformance requirements or test assertions." [^w3c]

# Note

From the glossary of the W3C Recommendation that guides how W3C specs are written; "informative" is also used interchangeably with "non-normative" across W3C documents. The same normative/informative split organizes conformance across every W3C spec — CSS, HTML, WAI-ARIA, and the rest — even where each spec restates it in its own words.

[^w3c]: QA Framework: Specification Guidelines, W3C Recommendation, 17 August 2005
