# About

The canonical statement of the web-scale knowledge-graph vision, twenty years before agents: data becomes explorable — by people *and machines* — through links. The four linked-data rules (URIs as names; HTTP URIs; useful information at lookup; links to more things) prefigure OKF's design almost item for item, at web scale rather than directory scale.
