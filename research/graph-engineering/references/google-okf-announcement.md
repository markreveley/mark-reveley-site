# About

The announcement post for the Open Knowledge Format. Positions OKF as the formalization of Karpathy's [LLM-wiki pattern](karpathy-llm-wiki.md): concepts as markdown files, identity as file path, and markdown links "turning the directory into a graph of relationships."
