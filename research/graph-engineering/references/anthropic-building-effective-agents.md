# About

The pre-history both camps cite. Workflows = LLMs orchestrated through predefined code paths (graphs, in 2026 language); agents = LLMs directing their own process (loops). [Bouchard](bouchard-what-actually-changed.md) claims this post "already drew every one of these patterns" in 2024. Its simplicity prescription is the standing counterweight to graph maximalism.
