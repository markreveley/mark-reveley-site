# About

The idea file behind the "LLM-wiki pattern": raw sources → LLM-maintained wiki of markdown pages with cross-references → schema document. Knowledge is compiled once and kept current. Two months later Google Cloud cited this gist as the pattern its [Open Knowledge Format](google-okf-announcement.md) formalizes. Quotes verified against the gist's raw text.
