# About

The directive that governs how every ISO and IEC standard is written. Clause 3.2 ("Elements of a document") gives the terms-and-definitions entries for `normative element` (3.2.1) and `informative element` (3.2.2) that every ISO/IEC standard's own structure depends on — which parts a reader must comply with to conform, and which parts merely help. `www.iso.org/sites/directives/current/part2/index.xhtml` (the current, 9th-edition copy) returned HTTP 403 to an unauthenticated fetch; this Metanorma-rendered 8th-edition sample matched raw, so it stands as the quoted source until the current edition can be fetched directly.
